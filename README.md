# TheaterLog

TheaterLog is a log of all of the musicals and plays I have seen since 2010. 

[View Live Project Here](https://theaterlog.com)

![TheaterLog Screenshots](readme/theaterlog-screenshot.png?raw=true "TheaterLog Screenshots")

## Features
The tracker is built using [Vue.js](https://vuejs.org/). The site consists of Show Cards that are created for each show seen. In the top hero section, there are statistics (number of shows seen, number of musicals seen, etc) as well as a guide to the review emojis.

### Statistics
The following statistics are tracked:
- Total number of shows seen
- Total number of upcoming shows
- Total number of musicals, plays and dances seen
- Total $ amount spent
- Average ticket cost
- Percentage of Broadway and West End theaters that I have seen a show in.
- Show cities
- Number of shows, cost of shows and average cost per show per year
- Seat locations
- Reviews
- Which shows were seen around my birthday
- Repeated shows


### Show Cards
Each show generates a card that includes the following:
- The show name 
- The theater and city of the show
- The month and year
- A label indicating if the show is a musical or a play
- Opinion Stickers:
  - A star if a show is a favorite
  - An emoji representing my review of the show
  - A numbered card displaying the number of times I have seen that particular show
- If a musical, my favorite song from the show (at the time of viewing) will be displayed.
